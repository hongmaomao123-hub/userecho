# 香氛产品使用体验问卷（草稿）

> 用问卷星、腾讯问卷或飞书问卷制作。目标是收回约 50–60 份，按每人最多填 2 款产品计，可以得到约 100 条反馈。
> 这份问卷的主要题目刻意设计成「写商品评价」的形式，这样收回来的文字才和电商评论风格接近，能直接作为 `feedback_text` 使用。

---

**开头说明（放在问卷首页）**

本问卷用于一个个人学习项目，研究香氛产品的用户体验。问卷匿名填写，不收集姓名、电话等身份信息。你的回答可能以匿名、改写后的形式出现在项目展示中，不会用于任何商业用途。继续作答即表示同意。

---

**Q1. 过去一年里，你买过或用过香氛类产品吗？**（单选，选「否」则结束问卷）
香薰蜡烛 / 无火香薰 / 香水 / 车载香氛 / 衣物香氛 / 其他

**Q2. 请选择一款你印象最深的香氛产品。它属于哪一类？**（单选）

**Q3. 请像写商品评价一样，写下你对这款产品的真实评价。**（必填，不少于 15 字）
可以写好的地方，也可以写不好的地方，比如：气味和预期是否一样、留香效果、包装和物流、价格、使用是否方便、客服，以及使用时有没有不舒服。

**Q4. 如果给这款产品打分，你会打几分？**（1–5 分）

**Q5. 你还会再买这款产品吗？**（单选）
会 / 不会 / 看情况 / 没想过

**Q6. 你是在哪里买的？**（单选）
淘宝·天猫 / 京东 / 小红书 / 抖音 / 线下门店 / 别人送的 / 其他

**Q7. 还想评价另一款香氛产品吗？**（选「是」则跳转到 Q2–Q6 的重复题组，最多再填 1 款）

---

## 数据整理规则（问卷回收后执行）

- 每一份问卷分配一个 `respondent_id`（R001、R002……）。每款产品算一条反馈，分配一个 `feedback_id`。
- Q3 → `feedback_text`，Q4 → `rating`，Q6 → `channel`。
- Q5 **不写入 CSV**，只作为人工标注 `repurchase_signal` 时的参考，这样可以检验系统能否仅凭评价文字判断复购信号。
- 问卷原始导出文件放在 `data/raw/`，不提交到 git。
- 按 `respondent_id` 随机划分数据集：约 45% 的人进入 eval，其余进入 dev。
